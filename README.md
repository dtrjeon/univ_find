# univ_find — 수지구 고교 교과과목 비교

용인시 수지구 5개 고등학교(수지고·신봉고·용인홍천고·성복고·서원고)의 교과·과목 편제표를 비교하고,
대학·학과별 권장과목을 어느 학교에서 들을 수 있는지 확인하는 단일 HTML 웹앱입니다. 학부모가 학생의 과목 선택을 지도하기 위한 도구입니다.

## 페이지

| 파일 | 내용 | 버전 파일 |
|---|---|---|
| `index.html` | 2026학년도 입학생 5개 학교 | `version.json` |
| `index_27년.html` | 2026 + 2027학년도 입학생(수지고·용인홍천고·서원고) 비교 | `version_27년.json` |

GitHub Pages: https://dtrjeon.github.io/univ_find/ (27년 페이지는 `index_27년.html`).
둘 다 서버 없이 동작하는 단일 파일이며, 페이지 로드 시 버전 파일을 읽어 새 버전이 있으면 안내합니다. 버전은 오른쪽 위에 표시됩니다.

## 화면 구성 (27년 페이지)

2. **비교할 고등학교** — 학교×입학년도 8개 체크박스(26년 5개, 27년 3개). 이름을 끌어서 열 순서 변경
3. **한눈에 보기** — 학교별 2·3학년 선택 풀, 고르는 수, 제2외국어
4. **전공으로 찾기 / 대학·학과별 유리한 과목** — 12개 대학 33개 모집단위의 권장과목과 학교별 이수 가능 여부
5. **학년별 과목** — 1·2·3학년 동시 선택, 비교표 / 학교별 카드, 학점과 택n 묶음 표시
6. **학교별 연도별 비교** — 같은 학교의 2026 대비 2027 추가·삭제·변경 과목
7. **과목별 개설 비교** — 2·3학년 과목이 어느 학교에서 개설되는지

한눈에 보기와 과목별 개설 비교는 선택한 학교·입학년도를 따르고, 대학·학과별 판정만 2026학년도 자료 기준입니다.

## 표시 규칙

- 파란 칸: 모두 이수하는 지정과목 / 점선 상자: 그 안에서 택n 과목을 고르는 선택 묶음 / 숫자: 학점
- `*` 수능 필수 과목이 아닌 과목, `**` 수능 선택 과목(과학 선택과목과 이어지는 과목)
- 빨간 `수능28(필수)` — 2028학년도 수능 필수 과목, 녹색 `수능28(선택)` — 수능 선택 과목
- "수능과 상관없는 과목(*) 숨기기" — 수능 필수·선택 과목만 남김

## 데이터 구조 (페이지 안 JavaScript)

- `Y[학교][학년]['1'|'2'] = {fx:[지정과목], pk:[[택n,[과목…]], …]}` — 2·3학년 학기별 편제
- `CR[학교][학년][학기] = {f:[지정 학점], p:[묶음별 과목당 학점]}` — 학점
- `Y1`, `Y1S` — 1학년 편성(학기별 목록)
- `Y27`, `CR27` — 2027학년도 입학생(수지고·용인홍천고·서원고), `YEARS={2026:{…},2027:{…}}`
- `UNIV`, `TAGS` — 대학·모집단위 권장과목, `REQ`/`SELX`/`X28` — 수능 필수·선택 과목 집합
- `KEYS`/`KSEL` — 비교 대상(학교|입학년도) 순서와 선택 상태, `planOf` — 권장과목을 학교 편제에 배정하는 판정 로직

## 자료 출처와 한계

- 수지고·용인홍천고·성복고·서원고 2026: 진학지도서 편제표 이미지 판독(성복고는 사진 판독, 학기별 학점 합계 일치 확인), 신봉고 2026: 학교 공시 PDF
- 2027: 용인홍천고(이미지 2장), 서원고(PDF, 2026 대비 한문·언어생활과 한자·한문 고전 읽기 삭제), 수지고(PDF, 2022 개정 과목명으로 개편)
- 성복고·신봉고 2027 편제표는 아직 없음
- 대학 입시결과(등급·점수)는 포함하지 않음. 연세대 2028 전공연계과목 가이드라인(2026.4) 포함, 나머지 대학은 각 대학 공개 자료 기준
- 학교 편제표는 학교와 연도에 따라 바뀔 수 있으므로 지원 전 학교 공시와 대학 요강을 반드시 확인
